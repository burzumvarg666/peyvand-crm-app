The workspace snapshot exports application data only; it is not a complete database or Auth backup. The application may merge missing records, returns and samples from a same-workspace snapshot; it does not overwrite existing data or restore members or Auth credentials; missing record audit entries are restored with an explicit archive provenance marker. The archive includes un-restored recycle-bin entries, but the file recovery workflow does not yet restore the recycle bin or return/sample activity logs. The privileged full replacement exercised by the round-trip test is a prototype, not a production restoration procedure.

Run `workspace-snapshot.sql` only against a disposable database after applying the migrations. For the in-memory round-trip test, install `@electric-sql/pglite@0.5.13` locally without changing production dependencies, then run `node tests/workspace-snapshot-roundtrip.mjs`. The test covers recycle-bin access, tenant isolation and restoration using synthetic users; it does not test real Supabase Auth, credentials, storage objects, platform configuration, or full recovery over existing data. The privileged round-trip setup bypasses triggers solely as a test fixture.
