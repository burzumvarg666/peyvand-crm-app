# پیوند CRM برای ویندوز

نسخه ۰.۵.۰ — فارسی، راست‌به‌چپ، آفلاین و تک‌کاربره

## اجرا و شروع

1. فایل `Peyvand-CRM-0.5.0-Windows-x64.exe` را در یک پوشه دلخواه ذخیره کنید و روی آن دوبار کلیک کنید.
2. این نسخه بدون نیاز به نصب اجرا می‌شود؛ در صورت نیاز خودتان برای فایل میان‌بر دسکتاپ بسازید.
3. در اولین اجرا نام شرکت یا فضای کاری خود را وارد کنید.
4. از «مشتریان» اولین مشتری را ثبت کنید، سپس مخاطب، فرصت فروش و پیگیری‌های او را اضافه کنید.

برنامه و داده‌های جدید خالی شروع می‌شوند؛ نمونه‌های نسخه نمایشی وارد پایگاه داده شما نمی‌شوند. برای اجرا، برای کار روزمره به مرورگر، Node.js، Vercel، Supabase یا اتصال اینترنت نیاز ندارید.

## ذخیره اطلاعات

اطلاعات در پایگاه داده SQLite در پروفایل همان کاربر ویندوز ذخیره می‌شود. محل پیش‌فرض:

`%APPDATA%\Peyvand CRM\peyvand.sqlite`

هر حساب ویندوز فضای ذخیره جداگانه دارد. حفاظت از ورود به این نسخه بر عهده حساب ویندوز است؛ برنامه رمز ورود جداگانه و کاربر تیمی ندارد. اطلاعات با نسخه آنلاین یا رایانه دیگر همگام نمی‌شوند.

## پشتیبان و انتقال به رایانه دیگر

از منوی «پرونده» بالای پنجره، «ذخیره پشتیبان» را انتخاب کنید. فایل JSON حاصل شامل نام فضای کاری، مشتریان، مخاطبان، فرصت‌ها، پیگیری‌ها، یادداشت‌ها و تاریخچه است.

برای انتقال، فایل اجرایی برنامه را روی رایانه مقصد کپی و اجرا کنید و از «پرونده ← بازیابی پشتیبان» فایل را انتخاب کنید. بازیابی پس از تأیید شما تمام اطلاعات فعلی را جایگزین می‌کند. پیش از جایگزینی، نسخه‌ای از اطلاعات فعلی در پوشه `backups` کنار پایگاه داده نگهداری می‌شود.

هنگام اجرای برنامه، فایل SQLite را به تنهایی کپی نکنید؛ از پشتیبان داخل برنامه استفاده کنید تا همه تغییرات ذخیره‌شده در پشتیبان باشند. خروجی CSV برای گزارش‌گیری است، نه بازیابی کامل.

## امکانات نسخه ویندوز

- داشبورد گرافیکی با نمودار روند فروش، نرخ موفقیت، وضعیت پیش‌فاکتورها و هشدار موجودی
- مدیریت مشتریان، مخاطبان، فرصت‌های فروش و پایپ‌لاین شش‌مرحله‌ای با جابه‌جایی کارت‌ها
- کاتالوگ محصولات، موجودی اولیه، ورود، خروج، اصلاح شمارش و دفتر immutable گردش انبار
- پیش‌فاکتور چندقلمی با تخفیف، مالیات، خروجی Excel و چاپ/ذخیره PDF
- قانون‌های اتوماسیون فروش برای تغییر مرحله، پایان اعتبار پیش‌فاکتور و پیگیری عقب‌افتاده
- ثبت یادداشت و تاریخچه تغییرات
- جست‌وجو و فیلتر، گزارش فروش و خروجی CSV و Excel
- تمام تاریخ‌ها با تقویم شمسی در نمایش و ورود اطلاعات، مبالغ به تومان
- پایگاه داده محلی و ماندگاری اطلاعات پس از بستن برنامه
- پشتیبان‌گیری کامل و بازیابی تراکنشی
- جلوگیری از بازنویسی تغییرات جدید با نسخه قدیمی رکورد
- منوهای فارسی، میان‌برهای کپی/چسباندن، بزرگ‌نمایی و تمام‌صفحه

این نسخه بدون نیاز به نصب برای ویندوز ۶۴بیتی ساخته شده است. فایل اجرایی امضای دیجیتال تجاری ندارد. اجرای رابط روی یک دستگاه واقعی ویندوز در محیط ساخت انجام نشده؛ این مرحله از آزمون پذیرش هنوز باقی است. «بدون نیاز به نصب» به معنای ذخیره داده کنار فایل EXE نیست؛ داده در پروفایل کاربر ویندوز باقی می‌ماند.

## اطلاعات فنی برای توسعه‌دهنده

رابط اصلی React برنامه وب در یک بسته مستقل Vite استفاده شده است. Electron 44.2.0 پنجره را اجرا می‌کند. SQLite داخلی Node در پردازش اصلی داده‌ها را ذخیره می‌کند. سرویس محلی فقط روی `127.0.0.1` و درگاه تصادفی گوش می‌دهد و هر درخواست به کوکی تصادفی HttpOnly همان اجرای برنامه نیاز دارد. درخواست‌های تغییردهنده علاوه بر کوکی، کنترل مبدأ دارند. دسترسی Node در renderer خاموش، context isolation و sandbox روشن، پنجره‌های خارجی و دسترسی شبکه غیرمحلی مسدودند.

ساخت از کد منبع (Node.js 24):

```bash
npm ci --legacy-peer-deps
npm run build:desktop
npm run desktop
npm run portable:windows
npm run test:desktop
```

در مرحله نصب وابستگی و ساخت اولیه اینترنت لازم است؛ نسخه اجرایی برای کار آفلاین نیازی به آن ندارد.

خروجی فایل اجرایی در پوشه `windows-release` قرار می‌گیرد. ساختار نسخه وب و تنظیم Vercel در کد منبع حفظ شده‌اند؛ نسخه ویندوز از API محلی مستقل استفاده می‌کند.

مستندات مبنا:

- https://electronjs.org/docs/latest/tutorial/security
- https://electronjs.org/docs/latest/tutorial/context-isolation
- https://nodejs.org/api/sqlite.html

ساخت نصب‌کننده NSIS با دستور `npm run installer:windows` نیز تنظیم شده است، اما در محیط Linux این تحویل به دلیل نبود Wine کامل نشد؛ فایل تحویلی نسخه portable است.
